============================================
🦞 销售作战中心 v3.1 · DEMO 体验说明
============================================

【这是什么】
这是一个销售工作台原型，用来收集你的真实使用反馈。
还没接真实数据，所有客户名/消耗/ROI 都是模拟的。

【怎么打开】
1. 解压本文件夹到任意位置（桌面即可）
2. 双击打开 index.html
3. 推荐用 Chrome / Edge 浏览器（Safari 也能看）

【3个页面，建议按顺序看】

① index.html 销售作战中心首页（主入口）
   - 顶部 KPI 卡：消耗/客户/排名一眼看
   - 4 个 Tab：首页 / 关注信息 / 关键客户 / 拓客工作流
   - 重点试试「关键客户」表的"今日实时消耗"和"一键联系"按钮

② 靶向品牌池_v3.html（核心新功能！）
   - 通过首页的"拓客工作流" → "靶向品牌池"进入
   - 看到未建联的 S/A 级品牌可以点 🎯 认领
   - 认领后可以持续 📝 更新进展（9个跟进阶段）
   - 切换"我认领的"视图，只看自己的盘子

③ 拓客作战看板_v3.html
   - 通过首页的"拓客工作流"进入
   - 各种维度的拓客图表

【请重点反馈这4个问题】
1. 「认领+更新进展」的流程合不合一线习惯？9个阶段够不够用？
2. 红点/快讯条/KPI卡，你最关心的信息是哪个？哪些是噪音？
3. 客户表里哪些字段缺失了你最想看到的？
4. 整体如果上线，你愿意每天用吗？还是觉得是负担？

【怎么提建议】
方式1：打开 index.html，点顶部黄色提示条的"📝 提建议"，填完点复制，
       粘贴到企微发给金洁（橘子）即可。
方式2：直接企微/邮件发给金洁。

【常见问题】
Q：为什么我填的认领/进展刷新就没了？
A：这是 demo 版，没接后端，正式版会保存。

Q：为什么没看到我负责的客户？
A：当前是模拟数据，正式版会接你真实的客户盘。

Q：能多人协作吗？
A：当前不能，正式版会支持。
