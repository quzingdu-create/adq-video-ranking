# 产品功能清单

版本：V0 baseline  
日期：2026-06-22

## 不变边界

本轮 CloudBase 重构不改变产品设计、不调整 UI 视觉、不改业务口径。所有改造围绕数据读取架构、接口边界、性能和可维护性。

## 主要页面

| 页面 | 职责 | 本轮处理 |
|---|---|---|
| `index.html` | PC 总入口、首页 KPI、今日待办入口、iframe 容器 | 仅接入 adapter 脚本 |
| `kanban_embed.html` | 作战中心主体、拓客明细、生命周期、产业带等模块 | 仅接入 adapter 脚本 |
| `mobile.html` | 移动端/小红点页面 | 仅接入 adapter 脚本 |
| `industry-belt.html` | 产业带专项 | V1 不改 |
| `pursuit.html` | 拓客/追踪专项 | V1 不改 |
| `monitor.html` | 登录时长监控 | V1 不改 |

## 主要业务模块

- 首页 KPI：服饰中心大盘、QTD 新客、有效新客、新锐、新客消耗。
- 今日待办小红点：Top 客户预警、处理进度、销售维度切换。
- 拓客登记：登记、批量导入、查重、归属、编辑、导出。
- 拓客明细：客户维度查询、销售筛选、状态展示。
- 客户生命周期：客户状态、阶段、跟进和详情。
- 红黑榜/潜力榜：涨跌榜、起量客户、昨日新增投放客户。
- 产业带/专项页面：行业与区域专题分析。

## V1 验收口径

- 默认访问仍为旧静态数据链路。
- 页面视觉不变化。
- 原有按钮、tab、iframe 关系不变化。
- 新增 API 骨架不主动请求云端，除非显式 `?dataMode=cloud` 或调用测试函数。
